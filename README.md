# Campus Crumbs Bakery POS System

## Project Description

Campus Crumbs Bakery POS System is a computer-based food ordering and Point-of-Sale (POS) application developed for the IT 415 – Application Development and Emerging Technologies Midterm Practical Examination.

The system is designed for a small campus bakery that sells bread, pastries, baked goods, and beverages. It allows the cashier to select products, manage customer orders, calculate the total amount, process cash payments, and generate digital receipts.

The application is developed using HTML, CSS, and JavaScript, featuring a simple and user-friendly interface with a warm brown-themed bakery design.

## Features

- **Product Display:** Displays six bakery products with their corresponding prices and Add to Cart buttons.
- **Shopping Cart Management:** Allows users to add products, increase or decrease quantities, and remove items from the cart.
- **Automatic Calculation:** Automatically calculates item subtotals and the total amount based on selected products and quantities.
- **Cash Payment Processing:** Accepts cash payments and validates blank, invalid, negative, and insufficient payment amounts.
- **Change Calculation:** Automatically calculates the customer's change after a successful payment.
- **Digital Receipt:** Generates a receipt containing the transaction reference number, date and time, purchased items, quantities, unit prices, subtotals, total amount, cash paid, and change.
- **New Transaction:** Allows the cashier to start another transaction by clearing the previous order, payment details, and receipt.
- **User-Friendly Interface:** Provides a clean, organized, and brown-themed layout suitable for desktop and laptop computers.

## How to Run the Application

1. Download or clone the GitHub repository.
2. Open the project folder in Visual Studio Code or File Explorer.
3. Make sure the following files are in the same folder:
   - `index.html`
   - `style.css`
   - `script.js`
4. Open `index.html` using a web browser such as Google Chrome or Microsoft Edge.
5. The Campus Crumbs Bakery POS System is ready to use.

No database, additional installation, or internet connection is required.

## How to Use

1. Browse the available bakery products.
2. Click **Add to Cart** to select products.
3. Adjust quantities using the **+** and **−** buttons or remove products using the **Remove** button.
4. Review the order summary and total amount.
5. Enter the customer's cash payment.
6. Click **Confirm Payment** to validate the payment and calculate the change.
7. View the digital receipt after successful payment.
8. Click **New Transaction** to clear the previous transaction and serve another customer.

## Project Limitations

- The system only supports cash payments.
- It does not require user authentication or login.
- It does not include inventory management.
- Transaction data is stored temporarily using JavaScript variables and arrays.
- Transaction information is not permanently saved after the browser page is refreshed or closed.
